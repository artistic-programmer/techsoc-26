# TechSoc Design System

## Visual Direction

Neo-Brutalist technical community website.

The provided design references are the source of truth for visual implementation.

## Colors

Primary:
- Black
- Off-white / warm white
- TechSoc blue

Accent colors:
- Yellow
- Green
- Pink / red
- Light blue

Use accent colors selectively for:
- badges
- buttons
- highlights
- section markers
- cards

## Typography

- Large, bold display headings
- Strong uppercase headings where shown
- Compact technical labels
- Highly readable body text
- Clear hierarchy between heading, description and metadata

Typography should match the supplied references as closely as possible.

## Borders

- Strong black borders
- Consistent border thickness
- Minimal corner rounding
- Cards should feel structured and physical

## Shadows

Use hard offset shadows.

Avoid:
- soft shadows
- blurred shadows
- glass effects

## Cards

Cards generally use:
- solid background
- black border
- hard offset shadow
- compact metadata
- clear hierarchy
- small accent labels/badges

## Layout

Use:
- strong section separation
- asymmetric compositions where shown
- structured grids
- generous but controlled whitespace
- editorial/technical layouts

Do not make every section symmetrical.

## Buttons

Buttons should:
- have strong borders
- use hard shadows where shown
- have clear text
- use accent colors selectively
- provide obvious hover/focus states

## Imagery

Prefer actual TechSoc photographs and project screenshots.

Do not replace supplied images with random stock imagery.

## Animation

Keep animation subtle:
- entrance transitions
- hover movement
- button interaction
- small page transitions

Never let animation overpower the design.

## Responsive Design

The design must work across:
- desktop
- tablet
- mobile

Do not simply scale down desktop layouts.

Reorganize grids and sections appropriately for smaller screens.

## Important Rule

Do not invent a new visual style.

When implementing a component, compare it against the supplied design references and preserve:
- proportions
- spacing
- typography hierarchy
- colors
- borders
- shadows
- alignment
- visual density
