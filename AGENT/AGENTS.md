# TechSoc Development Guidelines

## Project
Official TechSoc website for IIIT Bhubaneswar.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Design
- Neo-Brutalist visual style
- Bold typography
- Thick black borders
- Hard shadows
- Off-white backgrounds
- Yellow, blue, green and pink accents
- Minimal rounded corners

## Rules
- Prioritize visual fidelity to the provided design references.
- Do not redesign unless explicitly asked.
- Use reusable components.
- Keep content separate from UI.
- Do not hardcode events, team members or projects inside components.
- No login/signup/authentication.
- No database unless explicitly requested.
- Use the official TechSoc logo.
- Do not fabricate factual content.
